Device Tree - rabbit r1 (r1)
===============================================================

The Rabbit R1 is an AI-powered personal assistant device developed by Rabbit Inc., designed to simplify daily tasks through voice commands and touch interactions.

================================================================

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core 2.3 GHz Cortex-A53
Chipset | MediaTek Helio P35 (12nm)
GPU     | PowerVR GE8320
Memory  | 4 GB
Shipped Android Version | Android 13, rabbitOS AOSP
Storage | 128 GB 
MicroSD | NA
Battery | Li-Po 1000 mAh, non-removable
Dimensions | 78 mm x 78 mm x 13 mm (3 in x 3 in x 0.5 in)
Display | 2.88-inch TFT touchscreen, 60Hz
Rear Camera  | 	8 MP, 3264x2448 resolution, 1080p video at 24 fps
Front Camera | 	Rear-Camera can be used as Front Camera
Release Month | 2024, Jan 9
